# AI Web Economy Simulator

**[View the live simulator](https://ilanstrauss.github.io/ai-web-economy-simulator/)**

> **Note:** This is a rough work in progress.

An interactive simulation modeling how AI platforms and web content creators interact economically. Uses Lotka-Volterra population dynamics combined with mechanism design theory to explore different policy scenarios.

## Features

- Real-time ecosystem dynamics visualization
- Adjustable parameters: compensation rate, extraction intensity, mutualism benefit, traffic diversion
- Pre-built policy scenarios (Status Quo, Licensing Regime, Fair Deal, Traffic Collapse)
- Mechanism design analysis (IR/IC constraints)
- Calibrated to real-world data from AI licensing deals, journalism employment trends, and search diversion rates
